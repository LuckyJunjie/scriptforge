## 4.1 剧情树数据结构

### JSON 结构

```json
{
  "root": {
    "id": "root",
    "content": {
      "type": "scene",
      "location": "主角家中",
      "time": "深夜",
      "action": "门外传来急促的敲门声...",
      "dialogue": "主角: 谁啊？..."
    },
    "options": [
      { "id": "1", "text": "A. 开门去看看", "targetId": "node-a" },
      { "id": "2", "text": "B. 不予理会", "targetId": "node-b" }
    ],
    "children": ["node-a", "node-b"]
  }
}
```

### 节点类型

| 类型 | 说明 |
|------|------|
| scene | 场景 |
| dialogue | 对话 |
| action | 动作 |
| choice | 选项节点 |
