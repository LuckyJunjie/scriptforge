## 5.1 移动端阅读器

### 界面特点

- 简洁阅读体验
- 分支选项突出
- 阅读进度显示
- 夜间模式支持

### 阅读流程

```
加载剧本 → 显示当前节点 → 用户选择 → 跳转下一节点 → 记录选择 → 完成后统计
```

### 数据埋点

| 事件 | 说明 |
|------|------|
| page_view | 页面访问 |
| choice_select | 选项选择 |
| branch_reach | 分支到达 |
| complete | 完成阅读 |

## 5.2 分享链接系统

### 创建链接

```http
POST /api/share
{
  "scriptId": "123",
  "isPublic": true,
  "password": "可选",
  "expiresAt": "可选时间"
}
```

### 返回

```json
{
  "code": "abc123",
  "url": "https://scriptforge.app/s/abc123"
}
```

### 访问控制

- 公开链接: 无需验证
- 私密链接: 需要密码
- 付费链接: 需要购买
