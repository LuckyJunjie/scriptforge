## 6.1 用户管理

### 功能列表

- 用户列表 (分页/筛选)
- 角色修改
- 账号禁用/启用
- 用户详情查看

### 管理员操作

```http
PUT /api/admin/user/{id}/role
{
  "role": "admin"
}

PUT /api/admin/user/{id}/status
{
  "status": 0  // 禁用
}
```

## 6.2 内容审核

### 审核流程

1. 待审核列表
2. 查看内容详情
3. 通过/驳回/下架
4. 举报处理

### 审核操作

```http
POST /api/admin/review/{scriptId}/approve
POST /api/admin/review/{scriptId}/reject
POST /api/admin/review/{scriptId}/ban
```
